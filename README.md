# 勤休預定表產生器

> 派出所每月**勤休預定表**的產生、預覽與輸出，一次完成。

單機桌面程式，不需安裝、不需網路、不需資料庫伺服器——下載後雙擊就能用。承辦人只要維護人員名單與輪番規則，每個月的番號推算、A3 版面與 Excel／PDF 輸出都交給程式處理。

## 能幫你省下什麼

| 以前怎麼做 | 用這個程式 |
|-----------|-----------|
| 拿上個月的表，逐人往後推一格、跨月再接著算 | **按「接續上月」**，規則、名單與番號自動延續 |
| 規則改了就整張表重抄一次 | **按「自訂起始」**，選模板、配好 1 日番號，程式推到月底 |
| 不同方案各留一份紙本或試算表 | **模板可存多份**，群組、番號、輪休與代碼都是設定 |
| 改了規則或改個名字，舊表跟著變樣 | 月表產生時**另存一份快照**，歷史月份不受後續變更影響 |
| Excel 排一次、PDF 再排一次 | 按一次**匯出**，同時得到 A3 橫式 `.xlsx` 與 `.pdf` |
| 想到才手動複製一份資料庫備份 | 每天第一次開啟**自動備份**（日／週／月輪替），可加異地位置 |

> 💡 **接續上月 vs. 自訂起始**：番號沒有要動，就按「接續上月」；第一次產生、換了模板，或要重新安排誰站哪一格，就按「自訂起始」。程式不會替你判斷該走哪一條——這是刻意的，接續與否由承辦人決定。

## 主要功能

程式開啟後是四個分頁，由左至右依使用頻率排列。**每一頁右上角都有「？」**，點下去就是該頁的完整操作說明。

| 分頁 | 做什麼 |
|------|--------|
| **產生月表** | 選年月，用「接續上月」或「自訂起始」產生；預覽、覆蓋、刪除，以及匯出 Excel 與 PDF |
| **輪番設定** | 維護多份輪番模板：群組、番號範圍、輪休、固定番、反向排序與自訂代碼 |
| **人員設定** | 名單的新增、修改、排序，女警標記與在職／離職 |
| **功能維護** | 月表標題（單位名稱）、資料庫備份與異地備份位置、壓縮資料庫 |

**輪番規則是資料，不是寫死的程式**——番號用列印頁數那種範圍寫法（`1-20`、`21-25`、`A-F`）一次定義，儲存後將每個番號展開，點一下可切換輪休，雙擊可改成自訂代碼：

![輪番設定分頁，右側以勤休欄位呈現輪休與工作狀態](docs/img/03-rules.png?v=0.1.2)

> 💡 **名詞速查**
> - **群組**：月表上一整區欄位，例如大輪番、固定番、幹部。
> - **番號**：每個人當天的代碼，紙本上寫在格子裡的那個數字或字母。
> - **輪休**：槽位序列裡的休假格，月表印「休」並標紅。
> - **固定番**：番號不隨日期前進的群組。
> - **空白欄**：只印欄位與格線、供手寫的區塊（例如劃假、快打勤務）。

**群組設定走彈窗**——模式、番號範圍、左側日期欄、反向排序與註記都在這裡設定。改了模式或範圍會先提醒，確認後才清掉原本的輪休與自訂代碼：

![修改輪番群組的模式、範圍與版面設定](docs/img/04-group-dialog.png?v=0.1.2)

**人員名單不綁在模板裡**——誰在哪一組、站第幾格，是產生月表時才配的。離職人員只是不再出現在新的配對名單，舊月表仍保留當時的姓名：

![人員設定分頁，顯示排序、姓名、女警與在職狀態](docs/img/05-personnel.png?v=0.1.2)

**配對在一個視窗裡完成**——左側逐格指定人員（可打字篩選），右側是在職名單，點名字就帶進目前那一格；已配的人會標出所在欄位，不會從名單消失：

![自訂起始配對視窗，左側逐格配對、右側顯示在職人員](docs/img/02-pairing.png?v=0.1.2)

> 💡 **每一格都要有人**：包含輪休那幾格（就是那天休假的人）。沒配完不能按確定，畫面會標出還差哪幾格。

**產生後立刻看得到整張表**——預覽預設左右填滿，滾輪縮放、按住左鍵拖曳移動；看過再匯出，不必先產檔再開 Excel 檢查。

**維護與備份集中在一頁**——月表標題印的單位名稱、異地備份位置、立即備份與壓縮資料庫：

![功能維護分頁，顯示月表標題與資料庫維護功能](docs/img/06-maintenance.png?v=0.1.2)

**操作有疑問不必離開程式**——點分頁右上角的「？」：

![產生月表分頁的程式內使用指引](docs/img/07-help.png?v=0.1.2)

## 快速開始

### 1. 下載

到 [**最新版下載頁**](https://github.com/jerrygskk/PoliceRotaSys/releases/latest) 下載 `PoliceRotaSys.exe`。同一頁也提供兩頁的 **PDF 快速指引**，可列印放在桌上速查。

### 2. 擺放

建立一個專用資料夾，把 `PoliceRotaSys.exe` 放進去再開啟。第一次開啟會在同一個資料夾建立 `dbfile.db`，裡面附一份虛構的示範名單與範例模板。

> ⚠️ 人員、模板與歷次月表全都在 `dbfile.db` 這一個檔案裡。程式與它要放在一起，不要刪除或用空白檔覆蓋。

### 3. 首次設定與第一份月表

1. 到「**人員設定**」把示範假名改成單位名單，確認排序、在職狀態與女警標記。
2. 到「**輪番設定**」修改範例模板，確認各群組的模式、番號範圍、輪休與欄位順序。
3. 到「**功能維護 → 月表標題**」填入要印在月表上的單位名稱。
4. 回「**產生月表**」選年月，第一次請用「**自訂起始**」完成配對；產生後看過預覽，再按「**匯出**」。

## 常見問題

**Q：什麼時候用「接續上月」，什麼時候用「自訂起始」？**
番號與名單照上個月繼續，用「接續上月」；第一次產生、換模板，或要重新安排 1 日番號，用「自訂起始」。上個月還沒有月表時按「接續上月」會提示改用自訂起始。

**Q：修改模板、改名或把人員設為離職，會動到已經產生的月表嗎？**
不會。每個月產生時都會把當時的規則、姓名順序與 1 日起始欄位另存一份，預覽與重新匯出都讀自己那一份。這也是模板可以隨時改、隨時刪的原因。

**Q：月表產生錯了，可以重做或刪掉嗎？**
可以。已產生的月份照樣能按「接續上月」或「自訂起始」，確認後覆蓋原本的月表；也可以按「刪除月表」。**過去月份會多一次提醒**，但不硬擋。覆蓋與刪除都無法復原，重要資料請先用「立即備份」留一份。

**Q：已經匯出的 Excel／PDF 要重印怎麼辦？**
選回那個月份直接按「匯出」，程式會從該月的快照重新產生兩個檔案。刪除程式內的月表不會刪掉先前匯出的檔案。

**Q：資料會不會不見？**
每天第一次開啟程式會自動備份到程式旁的 `backups` 資料夾，保留最近 7 天、4 週與 12 個月。也可以到「**功能維護 → 資料庫備份**」指定一個**異地備份位置**（另一顆硬碟或網路磁碟），開啟程式時會一併備份一份過去，防範整顆硬碟故障。按「立即備份」建立的備份不參與自動輪替，不會被刪掉。

**Q：資料損毀或誤刪，怎麼從備份救回？**
程式不提供還原按鈕。請先關閉程式，保留現有檔案，再從 `backups` 挑一份備份複製到程式旁，改名為 `dbfile.db` 覆蓋回去。

**Q：要換電腦或搬資料夾，該帶哪些檔案？**
先關閉程式，再把 `PoliceRotaSys.exe`、`dbfile.db` 與 `backups` 資料夾一起複製到新位置。原本設了異地備份位置的話，搬完到「功能維護」確認那個路徑還連得上。

**Q：如何更新版本？**
先關閉程式，從最新版下載頁取得新的 `PoliceRotaSys.exe`，**只替換執行檔**。不要刪除或覆蓋原本的 `dbfile.db`；新版需要的欄位會在開啟時自動補上。

**Q：資料庫疑似損毀，程式打不開怎麼辦？**
程式每次開啟都會檢查資料庫，確定損毀時會提示並停止開啟，避免損壞擴大。請保留現有檔案另存留底，再依上面「從備份救回」的方式處理。

**Q：需要安裝或連網嗎？**
都不需要。免安裝、雙擊即用，不連網際網路，也不必架設資料庫伺服器。
